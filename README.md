# IndicPDF for Claude

This plugin connects Claude to [IndicPDF](https://www.indicpdf.in), a document
service for Indian languages, and teaches Claude when to use it.

With it, Claude can:

- convert Word files, PDFs and PageMaker files typed in old Indian fonts
  (Kruti Dev, DevLys, Chanakya, Anu, Nudi, Bamini, SutonnyMJ, Shree-Lipi,
  Akruti and others) to editable Unicode Word files;
- turn Indian-language PDFs, scanned or not, into editable Word files with the
  layout kept;
- write the same text in another Indian script;
- read scans and photos of pages with OCR;
- translate documents between English and Indian languages;
- write Unicode text in an old font for Adobe PageMaker;
- say what a document is (language, font, scanned or not) before converting it.

## Setup

Install the plugin, then connect IndicPDF when Claude asks, signing in with
your IndicPDF account. An account is free at
[indicpdf.in](https://www.indicpdf.in/register).

## Costs

Conversions use the same free allowance and credits as the website. Past the
free allowance, Claude tells you the price and converts only if you agree.
Credits are bought on indicpdf.in.

## Privacy and support

Files are stored encrypted and deleted within 4 hours. See the
[privacy policy](https://www.indicpdf.in/privacy) and the
[connector documentation](https://www.indicpdf.in/connectors). Support:
contact@indicpdf.in.
